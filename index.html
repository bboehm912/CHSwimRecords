How to add documents
  1. Put files in the documents folder beside this page. Sub-folders become categories, for example documents/Rosters/.
  2. Put the season in the file name, like 2015-16 Roster.pdf.
  3. Run build-documents-index.ps1 to refresh documents/index.json, then commit the files.

The library must be opened from a web address (for example GitHub Pages) or a local server.
